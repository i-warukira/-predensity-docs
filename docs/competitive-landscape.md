# Competitive Landscape

| | **Predensity** | Polymarket | Perpetual Futures |
|---|---|---|---|
| Market structure | Continuous $$P(x,y)$$ surface | Discrete binary events | Continuous price only |
| Bet format | Range $$[y_1, y_2]$$ at time $$x$$ | Yes / No tokens | Long / Short |
| Liquidity | Self-funded from losing stakes | AMM, requires LPs | Order book |
| Resolution | Automatic oracle | Oracle, disputable | Mark price |
| Reward driver | Sharpness × Boldness × Lead time | Fixed odds at trade | P&L on size |
| Early exit | *No — locked until resolution* | Yes | Yes |
| Forecast output | Live $$P(x,y)$$ map | Per-market probabilities | Funding rate |
