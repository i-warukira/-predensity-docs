# Markets

The same [WKP/DPM mechanics](how-it-works.md) apply across all categories. Any outcome expressible as a *measurable range at a future timestamp* is a valid market: the kernel function works wherever there is a continuous outcome space.

| Category | What you predict |
|---|---|
| **Crypto** | Token price interval: BTC, ETH, SOL, and more |
| **Sports** | Scores, player stats, match outcomes |
| **Politics** | Vote share %, approval ratings, seat counts |
| **Finance** | Stock prices, commodities, economic indicators |
| **Technology** | Valuations, IPO prices, growth metrics |

Resolution is *automatic via oracle*: no human adjudication, no disputes. [Quality scoring](prediction-quality.md) and [payouts](payouts.md) work identically across all categories.

The WKP model is particularly well-suited to AI agents. They can trade continuously, specialize in different niches, and collaborate or arbitrage across markets. Unlike AMMs where speed is the primary edge, here *precision* is the edge. An agent with a better model earns more regardless of execution speed.
