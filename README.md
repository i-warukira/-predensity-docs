# Predensity Docs

Welcome to the official Predensity documentation.

Predensity is a decentralized prediction market built on Hedera where you earn real rewards for being bold, early, and accurate. Predict crypto prices, sports outcomes, political events, and more — and get paid more for going against the grain.
